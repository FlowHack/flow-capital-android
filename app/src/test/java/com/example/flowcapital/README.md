# Тесты FlowCapital

## Структура тестов

Тесты покрывают всю бизнес-логику приложения и разделены на классы по функциональности:

### PSPFlowTest - Премиум Стартовый Поток
- ✅ Расчёт коэффициентов по периодам (1-20)
- ✅ Начисления для каждого периода при номинале 5000₽
- ✅ Расчёт totalAccrued (всё в копилку / частично / реинвест)
- ✅ Длительность периода (14 дней)
- ✅ Логика кнопки взноса (активна/неактивна)
- ✅ Даты начала/конца периодов
- ✅ Полный сценарий из пользовательской истории

### NoviceFlowTest - Поток Новичка
- ✅ E-currency бонус (150% от взноса)
- ✅ Ежедневное начисление (2%)
- ✅ Нажатие кнопки (день 1, 2, 3+)
- ✅ Округление до 2 знаков
- ✅ Реинвест (добавление к потоку)
- ✅ Сохранение/изменение кошелька
- ✅ SUNDAY/MISSED записи
- ✅ Полный сценарий из пользовательской истории

### GrowingFlowTest - Растущий Поток
- ✅ E-currency бонусы (все пороги)
- ✅ Начальный расчёт (10000₽ → 20000₽)
- ✅ Нажатие кнопки (день 1, 2, n)
- ✅ Округление % до 3 знаков, сумм до 2 знаков
- ✅ Реинвест с кастомным %
- ✅ Корректировка (inFlow/accrual/percent/wallet)
- ✅ Лучшая дата (DROP_DAY)
- ✅ SUNDAY/MISSED записи
- ✅ Полный сценарий из пользовательской истории

### CommonLogicTest - Общая логика
- ✅ Сравнение дат (тот же день / разные дни)
- ✅ Цветовые коды с прозрачностью
- ✅ Парсинг чисел с запятой/точкой
- ✅ Все 20 коэффициентов ПСП

### ECurrencyBonusTest - E-currency бонусы
- ✅ Все пороги: 1000₽, 5000₽, 10000₽, 50000₽, 100000₽, 500000₽, 1000000₽
- ✅ Проверка граничных значений

### ValidationTest - Валидация
- ✅ Обязательность суммы взноса
- ✅ Требование % для РП
- ✅ Номинал ПСП (>0, не пустой)
- ✅ Валидация корректировки (хотя бы одно изменение)

### ForecastTest - Прогнозы
- ✅ Расчёт количества дней
- ✅ Исключение воскресений
- ✅ Конец цикла (поток доходит до 0)
- ✅ Лучшая дата (+1 день после DROP_DAY)

### FullScenarioTest - Интеграционные тесты
- ✅ Полный сценарий всех трёх потоков

## Запуск тестов

```bash
./gradlew test
```

## Ожидаемые результаты

Все тесты должны пройти успешно. Если какой-либо тест падает - это означает
нарушение бизнес-логики в коде приложения.
