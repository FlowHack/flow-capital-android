# Тесты приложения FlowCapital

## Структура тестов

### 1. FlowLogicTest.kt - Основная логика потоков
- **PSPFlowTest** - Тесты логики ПСП (Премиум Стартовый Поток)
  - Расчёт начислений по коэффициентам периодов
  - Расчёт totalAccrued
  - Проверка активности кнопки взноса
  
- **NoviceFlowTest** - Тесты логики ПН (Поток Новичка)
  - Расчёт бонуса при взносе
  - Ежедневное начисление
  - Проверка кнопки (воскресенье, один раз в день)
  
- **GrowingFlowTest** - Тесты логики РП (Растущий Поток)
  - E-currency бонусы
  - Ежедневное начисление с процентом
  - Расчёт лучшей даты

### 2. ForecastAndEdgeCaseTest.kt - Прогнозы и граничные случаи
- **ForecastTest** - Тесты прогнозов
  - Прогноз ПН до даты
  - Прогноз цикла ПН до нуля
  - Прогноз РП
  - Поиск лучшей даты РП
  
- **EdgeCaseTest** - Граничные случаи
  - Поток не может уйти в минус
  - Нулевой депозит
  - Границы бонусов
  
- **ExportFormatTest** - Формат экспорта
  - CSV формат для всех потоков
  
- **ButtonStateTest** - Состояние кнопок
  - Проверка активности/неактивности кнопок
  
- **RoundingTest** - Округление
  - Проверка отображения чисел

### 3. DialogValidationTest.kt - Валидация диалогов
- Тесты валидации для всех диалогов
  - ReinvestDialog (РП)
  - CorrectionDialog (РП)
  - NoviceReinvestDialog (ПН)
  - NoviceCorrectionDialog (ПН)
  - CreatePSPDialog
  - ContributionDialog
  - PspCorrectionDialog

## Запуск тестов

### В Android Studio:
1. Откройте панель Project
2. Перейдите в `app/src/test/java/com/example/flowcapital/`
3. Правый клик на папке или файле теста
4. Выберите "Run 'Tests in...'"
5. Или используйте `Run > Run 'Tests in...'`

### Через командную строку:
```bash
./gradlew test
```

### Запуск конкретного теста:
```bash
./gradlew test --tests "com.example.flowcapital.FlowLogicTest"
```

## Ожидаемые результаты

Все тесты должны пройти успешно. Если тест падает - это указывает на проблему в реализации.

## Ключевые проверки

### ПСП:
- Период 1: 30%, Период 2: 55.8%, Период 3: 78%, Период 4: 97.07%
- При номинале 5000: начисления = 1500, 2790, 3900, 4853.5
- После 3 периодов с полной копилкой: totalAccrued = 8190

### ПН:
- При депозите 10000: в потоке = 15000
- Ежедневное начисление 2%
- После нажатия: В потоке -300, Кошелёк +300

### РП:
- При депозите 10000: в потоке = 20000 (100% бонус)
- Начальный процент 0.1%
- +0.003% за каждое нажатие
