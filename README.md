## Описание

**FlowCapital** — мобильное приложение для управления личными финансами с использованием системы "финансовых потоков". Приложение помогает отслеживать начисления, взносы и прогнозировать доходность по различным типам инвестиционных стратегий.

### Поддерживаемые потоки

| Поток | Описание | Статус |
|-------|---------|--------|
| **Растущий Поток (РП)** | Прогрессивный рост начислений (+0.003/клик) | ✅ |
| **Поток Новичка (ПН)** | Стабильные 2% в день + 50% бонус, лимит 750 000 | ✅ |
| **Премиум Стартовый Поток (ПСП)** | 20 периодов × 14 дней с растущими коэффициентами | ✅ |

## Функции

### 📊 Основные возможности

- **Управление потоками** — создание, отслеживание и завершение финансовых потоков
- **Ежедневные начисления** — автоматический расчёт и отображение доходности
- **Реинвест** — реинвестирование накоплений в новые потоки
- **Корректировка** — исправление ошибок в истории операций

### 📅 Планирование

- **Напоминания** — push-уведомления о необходимости действий
- **Календарь** — визуализация периодов и сроков
- **История** — полная история всех операций
- **Расчёт потоков** — прогнозирование будущих начислений

### 💾 Экспорт данных

- **Excel экспорт** — выгрузка данных для анализа в таблицах
- **Прогнозы** — предварительный расчёт доходности

### 🌐 Встроенный браузер

- Быстрый доступ к связанным сервисам (potok.cash, sberkossa, e-id)
- Поддержка прокси (SOCKS5, MTProto)
- Сохранение сессий и cookies между переключениями
- Перемещаемая кнопка обновления страницы (запоминает позицию)

### 📸 Сканер QR-кодов

- Встроенный сканер для быстрого доступа к ресурсам

### 🔄 Автообновления

- Проверка новых версий через GitHub API
- Уведомление и загрузка обновлений

## Сборка

### Требования

- Android Studio Hedgehog (2023.1.1) или новее
- JDK 17+
- Android SDK 28+ (Android 9)
- AGP 9.2.0

### Debug-сборка

```bash
# Клонирование репозитория
git clone https://github.com/FlowHack/flow-capital-android.git
cd flow-capital-android

# Debug-сборка
./gradlew assembleDebug

# APK будет в: app/build/outputs/apk/debug/
```

### Установка на устройство

```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```
