# FlowCapital v0.8.5

Привет! Это обновление приложения Flow Capital.

## Новое
- Умные уведомления: напоминания и будильники теперь учитывают время клика по кнопке начисления. Уведомления срабатывают только после того, как кнопка стала активной, а в момент клика приходит штатное уведомление.

## Исправления
- Исправлена ошибка сборки на CI (Metaspace).
- Исправлен текст релиза: теперь корректно отображается в формате Markdown.

## Как обновиться
- Скачайте APK из этого релиза и установите его поверх текущей версии.
- Данные приложения сохранятся.
