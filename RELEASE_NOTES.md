# Привет, сообщество **FlowCapital**! 🌊

Версия **0.8.6** — обновление браузера и завершение умных уведомлений.

---

## ✨ Новое
- **Новые сайты в браузере:** добавлены **BlackBit** (`blackbit.exchange`) и **eRub** (`erub.site`) с фирменными иконками. Выбор сайта — по удержанию вкладки «Браузер».
- **Открытие ссылок извне:** приложение теперь появляется в системном списке «Открыть с помощью» для всех 5 сайтов (ПОТОКCASH, СБЕРКАССА, E-ID, BlackBit, eRub). При клике на ссылку сайта приложение открывает вкладку «Браузер» с нужным адресом.
- **Умные уведомления (завершены):** напоминания и будильники полностью переведены с WorkManager на AlarmManager — уведомления срабатывают вовремя, учитывая время клика по кнопке начисления.
- **Логи в файл:** системные логи теперь пишутся в файл с ротацией — удобнее диагностировать работу приложения.

---

## 🔧 Исправления
- **Иконки:** обновлены иконки ПОТОКCASH и СБЕРКАССА — теперь в едином качественном стиле с новыми сайтами.
- **Миграция напоминаний:** отменены устаревшие WorkManager-задачи при перепланировании и удалена старая система ReminderWorker — ничего не «висит» в фоне.

---

## 📲 Как обновиться?
1. Скачайте актуальный APK-файл внизу этой страницы.
2. Либо используйте встроенную функцию: **Настройки** → **Проверить обновления**.
> [!IMPORTANT]
> **Совет по безопасности:** Перед обновлением обязательно сделайте бэкап данных: `Настройки` → `Экспорт/Импорт` → `Экспорт`. Ваши данные — это ваша ценность! 🛡
